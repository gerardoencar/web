# 🌤️ Panel Meteorológico Interactivo para La Caleta, Santo Domingo

![Panel Meteorológico](screenshot.jpg)

Panel meteorológico interactivo desarrollado con HTML, CSS y JavaScript para Andrés en La Caleta, Campo Lindo, Santo Domingo, República Dominicana.

## Características Principales

- 📍 Mapa integrado de Google Maps mostrando la ubicación específica
- 🌡️ 9 secciones de información meteorológica
- 🔄 Actualización automática cada 30 segundos
- 📥 Botones interactivos para actualizar datos y descargar reportes
- 📱 Diseño completamente responsive
- 🇩🇴 Personalizado para el clima de República Dominicana

## Secciones de Información

1. **Pronóstico de lluvia** - Probabilidad e intensidad de lluvia
2. **Temperatura** - Máxima, mínima y actual
3. **Estado del tiempo** - Condiciones actuales
4. **Humedad y vientos** - Humedad relativa y velocidad del viento
5. **Estado del cielo** - Cobertura nubosa y visibilidad
6. **Estado del sol** - Horarios de amanecer/atardecer e índice UV
7. **Sensación térmica** - Temperatura percibida
8. **Nivel de frío** - Índice de frío y recomendaciones
9. **Pronóstico de nieve** - Probabilidad de nieve (siempre 0% en RD)

## Tecnologías Utilizadas

- **HTML5** - Estructura del panel
- **CSS3** - Diseño y animaciones
- **JavaScript** - Lógica e interacción
- **Google Maps API** - Mapa integrado
- **Font Awesome** - Iconos

## Cómo Usar

1. Clona el repositorio o descarga el archivo `index.html`
2. Abre el archivo en cualquier navegador moderno
3. Explora las diferentes secciones meteorológicas
4. Usa los botones para actualizar datos o descargar reportes

## Personalización

Puedes personalizar la ubicación modificando el iframe de Google Maps y ajustando los datos meteorológicos en el archivo JavaScript.
